Queenswood {{ .Chart.Version }} installed as {{ .Release.Name }} in {{ .Release.Namespace }}.

{{- if and .Values.gateway.enabled .Values.gateway.gcp.enabled }}

Public URL (once the LB + cert provision):
  https://{{ .Values.gateway.host }}

The regional external Application Load Balancer takes 5-10 minutes
to come up. The Certificate Manager certificate transitions
PROVISIONING -> ACTIVE over 15-60 minutes for the first issuance,
once the DNSAuthorization CNAME has propagated.

Check progress:
  kubectl -n {{ .Release.Namespace }} get gateway {{ .Release.Name }}-gateway
  kubectl --context kind-xp-mp get certificate.certificatemanager.gcp.upbound.io \
    queenswood-cert -o jsonpath='{.status.atProvider.managed.state}{"\n"}'

Registrar delegation (once-only):
The Cloud DNS managed zone is provisioned by Crossplane on the xp-mp
management cluster. Read its four nameservers and paste them as NS
records for the `queenswood` subdomain at your registrar:

  just gcp-dns-ns

If the cert sticks on PROVISIONING beyond ~30 min, check the
DNSAuthorization CNAME in Cloud DNS matches the value in
DNSAuthorization.status.atProvider.dnsResourceRecord, and confirm the
NS delegation at the registrar is correct -- all four
ns-cloud-cN.googledomains.com. values must be set.
{{- else if .Values.gateway.enabled }}

Gateway: enabled with host {{ .Values.gateway.host }} (non-GCP path).

Gateway: disabled. Port-forward each Service in a separate terminal
to reach the platform from your host:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-bank-api-service 8080:8080
{{- if .Values.bankApp.enabled }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-bank-app 8081:{{ .Values.bankApp.port }}
{{- end }}
{{- if .Values.bankConsole.enabled }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-bank-console 8082:{{ .Values.bankConsole.port }}
{{- end }}
{{- if .Values.keycloak.dev.enabled }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/queenswood-keycloak-keycloak-service 8090:8080
{{- end }}

Then open:
  http://localhost:8080/scalar       (bank-api OpenAPI)
{{- if .Values.bankApp.enabled }}
  http://localhost:8081              (bank-app -- operator console)
{{- end }}
{{- if .Values.bankConsole.enabled }}
  http://localhost:8082              (bank-console -- organisation sign-in)
{{- end }}
{{- if .Values.keycloak.dev.enabled }}
  http://localhost:8090              (Keycloak admin console -- admin / admin)
{{- end }}

To expose publicly on GKE, set --set gateway.enabled=true
--set gateway.gcp.enabled=true --set gateway.host=<your-host>.
